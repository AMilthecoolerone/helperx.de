Setup

How to set up the bot on your server

1
Invite the bot
Click "Invite Bot" in the navigation or use the direct link. Select your server and grant the required permissions.
2
Permissions
The bot requires the following permissions:
Administrator or: Manage Messages, Kick/Ban Members, Manage Voice Channels
3
Configuration
After inviting, you can see all commands using /. Choose the modules you want to enable.
4
Slash Commands
Slash commands are automatically registered after the first command. It may take up to 1 hour for all commands to become available in all channels.
